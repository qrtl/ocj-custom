To maintain the available classifications:

1. Go to *Inventory > Configuration > Equipment Classifications* (or
   *Equipment Sub-Classifications*).
2. Create the entries with a name and, preferably, a numeric code.

To classify a product:

1. Open a product.
2. In the *General Information* tab, select the **Equipment Classification**
   and **Equipment Sub-Classification**.

Products can be searched and filtered by either classification from the
product list view.
