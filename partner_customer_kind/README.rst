This module adds a **Customer Kind** selection to partners so a customer
can be classified as a hospital, a dealer, an individual or a veterinary
hospital.

The kind is a plain attribute of the partner. Other modules read it to
decide behaviour that differs by customer type, such as pricing, billing
or which downstream systems a customer is shared with.

Usage
=====

Open a partner, go to the *Sales & Purchase* tab and set **Customer
Kind** in the *Misc* group. The field is optional.
