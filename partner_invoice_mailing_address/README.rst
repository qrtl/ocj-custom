This module adds an **Invoice Mailing Address** field to customers. When
it is set, customer invoices and summary invoices printed with the
alternative layout show that address in place of the customer's own
address, under the customer's name and phone.

.. contents::
   :local:

Usage
=====

Go to *Contacts > Customer > Invoicing tab > Customer Invoices* and fill
in **Invoice Mailing Address** as follows:

::

   〒123-4567
   東京都千代田区サンプル町1-2-3 サンプルビル5F
   サンプルセンター気付
