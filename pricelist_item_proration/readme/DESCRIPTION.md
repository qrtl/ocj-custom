Rental prices are sometimes charged pro rata for a partial period and sometimes
in full, and which applies is a property of the customer *and* the product: the
same customer can be prorated on one piece of equipment and not on another.

This module records that on the pricelist item, which is already the place a
price is set per customer and product. Odoo does not compute the prorated
amount -- it carries whether to prorate, by which method, and how to round, for
whoever produces the invoice.
