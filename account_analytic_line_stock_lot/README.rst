This module shows the lot product and the lot/serial number of a journal
item on its analytic items.

Analytic items made from a journal item carry both values, so they can
be searched and grouped by lot/serial number, for example to total the
revenue and cost of one serial. Analytic items with no journal item
behind them, such as timesheets, have neither.
