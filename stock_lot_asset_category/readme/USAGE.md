To configure the asset categories, go to *Inventory > Configuration > Asset
Categories* and create the categories you need.

Once set, the values in the two steps below can be changed only by the group
described in the configuration.

To set the default of a product, open a product tracked by serial/lot number
and set **Default Asset Category** in the *Inventory* tab.

A serial/lot number created from then on (on a receipt, by import or by hand)
gets the default of its product. To change it for one unit, open the
serial/lot number (*Inventory > Products > Lots/Serial Numbers*) and set
**Asset Category**.

The asset category is also available as a column, a search field and a *Group
By* option in the serial/lot number and quant lists.
