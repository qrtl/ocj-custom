This module records who owns each serial/lot number in an **asset
category** (for example own asset, or an asset of the company it is
rented from).

A dedicated ``stock.lot.asset.category`` model holds the categories, so
they can be maintained by users instead of being hard-coded. The module
does not ship any category (they can be provided by a company-specific
data module).

Each product carries a **default asset category**. A new serial/lot
number takes it from its product, and it can then be changed on that
serial/lot number alone, for units that are an exception to their
product's default. Changing the default of a product does not change its
existing serial/lot numbers.

Because the asset category says who owns a unit, only the users of the
group *Assign Asset Categories to Products and Lots/Serials* can set it,
on a product or on a serial/lot number. For everybody else both fields
are read-only, in the forms and through imports alike.

Configuration
=============

Add the users who may set asset categories to the group *Assign Asset
Categories to Products and Lots/Serials* (*Settings > Users & Companies
> Groups*). The administrator is in it by default.

Usage
=====

To configure the asset categories, go to *Inventory > Configuration >
Asset Categories* and create the categories you need.

The two steps below need the group described in the configuration.

To set the default of a product, open a product tracked by serial/lot
number and set **Default Asset Category** in the *Inventory* tab.

A serial/lot number created from then on (on a receipt, by import or by
hand) gets the default of its product. To change it for one unit, open
the serial/lot number (*Inventory > Products > Lots/Serial Numbers*) and
set **Asset Category**.

The asset category is also available as a column, a search field and a
*Group By* option in the serial/lot number and quant lists.
