This module exports the journal entries of a period, once, as a CSV file
to be imported into the OBC accounting system (Kanjo Bugyo i-series,
"OBC receiving format" with the item codes in the first line).

The journal items are not exported one by one. They are summed per
account, sub-account, department and tax into one OBC entry per journal
and day. Cost of sales of invoices, and journals set so, make one entry
dated the last day of the month.

The export depends on the report_csv module from OCA.

Configuration
=============

- Give the accounts the OBC account codes. For an account that stands
  for an OBC sub-account, join the account code and the sub-account code
  with a period: ``111.2`` is exported as account ``111``, sub-account
  ``2``.
- Set *OBC Department Code* in the analytic accounts that stand for a
  department. Only income and expense journal items carry a department;
  the others are exported with the default department code.
- Set *OBC Tax Category* and *OBC Tax Rate Type* in the tax records. Tax
  amounts are exported as separate rows on the tax account, with the tax
  calculation of OBC turned off.
- In the journals (*Advanced Settings > OBC Export*), tick *Exclude from
  OBC Export* for the journals that must not reach OBC, and set *OBC
  Aggregation* to *Per Month* for the journals to sum into one month-end
  entry, such as the inventory valuation journal.
- In *Accounting > Configuration > Settings > OBC Export*, set the
  department code to export for journal items without a department.

Usage
=====

After the month is closed, go to *Accounting > Accounting > Closing >
OBC Exports*, create a record with the period (the previous month by
default), and click *Export CSV*.

The export takes the posted journal entries of the period that no export
has taken yet, and downloads the file. Clicking *Export CSV* again
downloads the same entries again.

An exported journal entry cannot be reset to draft. To export a period
again, an accounting administrator deletes the export record, which
releases its journal entries.
