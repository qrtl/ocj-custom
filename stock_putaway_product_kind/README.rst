This module adds a **Product Kind** to putaway rules (the kind set on
the product by ``product_classification``: Equipment, Accessory,
Consumable or Rental Fee). A rule with a product kind applies only to
products of that kind; a rule without one applies as in standard Odoo.

A rule with a product kind and no product or category is ranked like a
standard rule with neither: among such rules, the priority (sequence)
decides, and a rule whose priority was never set comes after those with
one.

Use Cases / Context
===================

Where the goods of a warehouse are split by product kind, for example
consumables kept in a shared location while equipment is kept elsewhere,
a standard putaway rule can only select them by product or by category.
When the consumables are spread over several categories, one rule per
category is needed in each warehouse, and a category added later is
missed until a rule is added for it. A single rule per warehouse
selecting the product kind covers them all.

Configuration
=============

1. Go to *Inventory > Configuration > Putaway Rules*.
2. Create a rule with **When product arrives in** and **Store to**, and
   set **Product Kind** instead of a product or a category.

Storage locations must be enabled in the inventory settings for the menu
to be shown.
