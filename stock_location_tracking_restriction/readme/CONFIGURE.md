1. Go to *Inventory > Configuration > Locations* and open the location.
2. Set **Accepted Products**. The field is shown for internal and virtual
   locations; set it on a virtual location to restrict all the locations under
   it.
3. Leave the field empty to accept any product, or to follow the setting of a
   parent location.

The **Accepted Products** column can be shown in the location list from the
optional columns.
