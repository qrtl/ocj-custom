To configure the available quality statuses:

1. Go to *Inventory > Configuration > Quality Statuses*.
2. The module does not ship any statuses. Create the statuses you need (or
   install a data module that provides them), then edit, reorder or archive them
   as needed.
3. Set the **shippability**, **major category**, **shipping priority** and
   **shippability note** of each status as required. The list is colour-coded by
   shippability (green = shippable, orange = conditional, red = not shippable).
4. Flag at most one status as **Default for New Lots**. New lots/serials will be
   created with that status.

To assign a quality status to a lot/serial number:

1. Open a serial/lot number (*Inventory > Products > Lots/Serial Numbers*).
2. Set the **Quality Status** field.

The status is also available as a column and as a *Group By* option in the lot/serial
number and quant lists.
